# NeoVim Integration Guide

Team of Six is designed to be invisible. Using plugins like `gp.nvim` (for LLM chat) and `octo.nvim` (for GitHub management), you can control the entire DevOps lifecycle without leaving your editor.

## 🤖 Configuring `gp.nvim`
Ensure you configure your `gp.nvim` setup to use a high-reasoning model (e.g., **Claude 3.5 Sonnet** or **GPT-4o**) as the default for the `TeamOfSix` chat. The system relies heavily on the LLM's ability to hold the "Mirror" state without prematurely writing executable code.

## The Lua Bridge
Add the `tos_bridge.lua` file to your NeoVim configuration. This provides the following commands:

* `:TosWork` - Injects the GitHub "Remote Truth" (fetched via `tos work`) directly into your active LLM chat buffer.
* `<leader>lr` (Visual Mode) - Highlights a bash script generated by the AI and pipes it directly into `/run/team_of_six/${USER}_input.sh`, then automatically triggers `tos wrapper`.

## Recommended "Zero-Context Switch" Workflow
1.  **Terminal:** `tos <project> work 123` (or `main` if starting fresh)
2.  **NeoVim:** `:GpChatNew TeamOfSix` -> `:TosWork`
3.  **NeoVim:** Discuss with AI. Highlight AI's output bash block -> `<leader>lr`
4.  **Terminal:** `tos <project> publish`
5.  **NeoVim:** `:Octo pr review`
